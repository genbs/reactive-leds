reactive-leds

Real-time LED control for ESP32-S3 over UDP & WebSocket

1 — Flash firmware

Connect your ESP32-S3 via USB, then click the button below. Requires Chrome or Edge.

Your browser doesn't support Web Serial. Use Chrome or Edge.

2 — Install CLI

Control the device from your terminal. Requires Node.js 18+.

npm install -g @reactive-leds/cli

Then run rleds --help to get started.

3 — Browser demo

Start the local proxy with rleds proxy, then connect here to control LEDs in real time. The proxy bridges WebSocket (browser) to UDP (device).

Client library not yet available on npm. Check releases.
