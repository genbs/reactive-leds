ESP32-S3 Firmware

The heart of the project: runs on the ESP32-S3, receives UDP commands and drives the LEDs in realtime with minimal latency. To install, plug in via USB and hit the button below. Chrome or Edge only.

Your browser doesn't support Web Serial. Try Chrome or Edge.

After flashing, run rleds bt-credential from the CLI to send WiFi credentials to the device over Bluetooth — once per device.

rleds CLI

The command-line tool for reactive-leds: scan, provision, control devices and run the WebSocket proxy — all from the terminal.

npm install -g @reactive-leds/cli

After installing, run rleds --help to see what's available.

Run rleds proxy to get started.
